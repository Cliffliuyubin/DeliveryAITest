# TVBox 扩展字段（fork 适配）

> 本文档登记原版 TVBox Wiki **之外** 的扩展字段；
> 这些字段以注释形式提供，并通过 `dist/source.json.flags` 启用，避免干扰原版客户端。

## 1. 启用机制

源 JSON 顶层 `flags` 是扩展开关数组：

```json
{ "flags": ["multi_warehouse_ext"] }
```

当 `flags` 包含特定 key 时，对应扩展字段才被 TVBox 客户端识别。

| Key | 含义 | 触发 |
|---|---|---|
| `multi_warehouse_ext` | 启用多仓扩展（推荐原版 + 多仓通用；本仓库默认开启） | 仓库默认 |
| `in_memory_mock_first` | 启用内置 mock spider（仅在仓库订阅时生效） | 仓库默认 |
| `disabled_marker` | 启用站点临时禁用标记（标记字段命名见 §3） | 由用户选择启用 |

> 自定义 flag key 由文档维护者追加，原版 / 多仓客户端会忽略未识别的 flag，不会出错。

## 2. Sites 扩展字段

下表只列出原版 Wiki **之外** 的可选字段；必须显式登记在文档中才允许使用。

| 字段 | 类型 | 含义 | 启用 flag |
|------|------|------|----------|
| `jar` | string | 蜘蛛包 URL（部分 fork 解析此字段代替 `api`） | `multi_warehouse_ext` |
| `ext` | string | base64 扩展信息（fork 字段，与本仓库明文 JSON 互斥） | — |
| `playerType` | number | 默认播放内核（部分 fork 支持 0/1/2） | `multi_warehouse_ext` |
| `timeout` | number | 单接口超时（毫秒） | — |
| `proxy` | string | 站级代理 | — |
| `custom` | object | 自定义参数，spider 通过 `base.config.custom` 访问 | — |

**注意**：本仓库不内置 `ext` 字段的实际值；如 fork 客户端强制 base64，请参考对应 fork 文档自行构造。

## 3. 站点临时禁用标记（OQ-003 推荐方案）

命名约定：`site.disabled_until`（unix 时间戳），落在 `site.custom.disabled_until`。

源 JSON 写法：

```json
{
  "key": "example-public",
  "name": "示例·公共模板",
  "custom": {
    "disabled_until": 1735689600000,
    "reason": "第三方 API 限流，临时关闭"
  }
}
```

Spider 文件应在 `init` 中读取：

```js
function init(_ext) {
  base.ext = _ext || {};
  var disabledUntil = (base.config.custom && base.config.custom.disabled_until) || 0;
  if (disabledUntil > Date.now()) {
    base.disabled = true;
    if (base.logger) base.logger.warn('init', { status: 'disabled', elapsed: 0, url: '', error: 'site_disabled_until=' + disabledUntil });
  }
  return {};
}
```

并在 6 接口中：

```js
if (base.disabled) {
  return tvboxBase.emptyListResult();
}
```

## 4. Pares / Rules 字段说明

| 顶层 | 形态 | 含义 |
|------|------|------|
| `parses` | 数组 | 解析器/云解析条目；`name` 唯一 |
| `rules` | 数组 | 嗅探 / UA 注入规则；典型结构 `{ host: '*', rule: [], ua: '...' }` |

默认仓库提供 1 条 parses + 1 条 rules，便于检查 fork 兼容性。如不需要可保留为空数组。

## 5. 兼容性策略

- **协议字段原版优先**：新增字段以注释补充；不可修改原版字段语义。
- **flag 缺失即禁用**：未在 `flags` 启用的字段，原版客户端忽略即可。
- **错误兜底**：扩展字段值非法时，Spider 必须返回 `{list:[]}` + WARN 日志，不得抛异常。

## 6. 验证

```bash
# 校验源 JSON 顶层协议字段 / 额外字段
node tools/scripts/validate-source.js dist/source.json tools/schemas/source.schema.json
```

> 当前 schema 已限定额外字段：`additionalProperties=false`，仅允许协议/扩展字段；新增字段必须同步改 schema 与文档。
