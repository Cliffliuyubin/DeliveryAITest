# TVBox 协议字段参考

> 本表为本地开发速查；权威定义请以 TVBox 上游 Wiki 为准。
> 多仓扩展字段另见 `docs/扩展字段.md`。

## 1. 源 JSON 顶层（REQ-002）

| Key | 类型 | 必填 | 含义 |
|---|---|---|---|
| `sites` | array | ✅ | 站点数组 |
| `parses` | array | ⛔ 可选 | 解析器集合 |
| `rules` | array | ⛔ 可选 | 嗅探/UA 注入规则 |
| `flags` | array | ⛔ 可选 | 扩展开关 |

> 不允许出现 `ext` / `lives` / `doh` / base64 / 暗链 等其他顶层键。

## 2. Sites 单元素字段

| Field | Type | Required | Description |
|---|---|---|---|
| `key` | string | ✅ | 唯一标识，源 JSON 内不重复 |
| `name` | string | ✅ | TVBox 端显示名 |
| `type` | number | ✅ | 1 = 影视；其它值见上游 Wiki |
| `api` | string | ✅ | Spider 入口 URL 或 jar 路径 |
| `jar` | string | ⛔ | 蜘蛛包 URL（fork 解析此字段） |
| `searchable` | 0/1 | ⛔ | 是否启用搜索 |
| `quickSearch` | 0/1 | ⛔ | 是否启用即时搜索 |
| `filterable` | 0/1 | ⛔ | 是否启用筛选 |
| `playerType` | number | ⛔ | 默认播放内核 |
| `timeout` | number | ⛔ | 单接口超时（毫秒） |
| `ua` | string | ⛔ | 默认 UA（覆盖 headers） |
| `headers` | object | ⛔ | 请求头 |
| `proxy` | string | ⛔ | 站级 HTTP 代理 |
| `ext` | string | ⛔ | fork 扩展 base64 |
| `custom` | object | ⛔ | 自定义参数；spider 通过 base.config.custom 访问 |

## 3. VodDetail 字段

| Field | Description |
|---|---|
| `vod_id` | 唯一 id（String） |
| `vod_name` | 剧名（String） |
| `vod_pic` | 封面 URL |
| `vod_remarks` | 备注（集数/状态） |
| `vod_year` | 年份 |
| `vod_area` | 地区 |
| `vod_content` | 简介 |
| `vod_play_from` | 播放来源标签 |
| `vod_play_url` | 播放 URL（见 §5） |
| `vod_tag` | 自定义 tag |

## 4. 6 接口返回值形态

| API | 返回 JSON |
|---|---|
| `init` | `{ ext: {...} }` 或 `{}` |
| `homeContent` | `{ class: [{type_id, type_name}], list: [VodItem], filters: {...} }` |
| `categoryContent` | `{ list: [VodItem], page, total, pagecount, filter, extend }` |
| `detailContent` | `{ list: [VodDetail] }` |
| `playerContent` | `{ url, parse, header?, flag?, vipFlags? }` |
| `searchContent` | `{ list: [VodItem], page, total, pagecount, key, quick }` |

`parse`：0 = 直链；1 = 走 `parses` 解析。

## 5. vod_play_url 格式

```
集数1$类型1$URL1#集数2$类型2$URL2#集数3$类型3$URL3
```

多个播放来源用 `$$$` 分隔：

```
<来源A>$$$<来源B>
```

示例：

```
第01集$mp4$https://cdn.example.com/v/001.m3u8#第02集$mp4$https://cdn.example.com/v/002.m3u8$$$备用$https://cdn.example.com/v/bak-001.m3u8
```

## 6. 异常与兜底

| 场景 | Spider 返回 | 日志 |
|---|---|---|
| 网络超时 | `{ list: [] }` | WARN（`fetch` 接口） |
| HTTP 非 2xx | `{ list: [] }` + 状态码 | WARN/ERROR |
| JSON 解析失败 | `{}` | ERROR |
| 站点改版缺字段 | `{ list: [] }` | WARN |
| 资源不可用 | `{ list: [] }` | ERROR |
| 成功 | 标准协议结构 | INFO |
