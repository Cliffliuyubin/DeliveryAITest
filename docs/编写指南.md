# Spider 编写指南

> 本文档是 TVBox Spider JS 的最小完整开发与调试指南；
> 配合仓库的 [README 末尾章节](../README.md) 与 [扩展字段文档](扩展字段.md) 使用。

---

## 0. 目标与原则

- 一句话：把一个影视/网盘站点接入到 TVBox，需要 6 个函数与一组配置；本指南要求 30 分钟内完成。
- 协议基线 = **原版 TVBox Wiki**；多仓扩展字段以注释提供并通过 `flags` 启用（见 `docs/扩展字段.md`）。
- **合规前置**：
  - 严禁在仓库内置已知盗版/版权侵权站点的：完整 URL、接口路径、解析特征、关键 Cookie/Token。
  - 接入第三方资源站前必须提交《资源站合规与责任清单》（U-1/U-2/U-3）。
  - 仓库不替用户完成侵权检测；CI 启用拦截请确认 `tools/scripts/check-compliance.sh`。

## 2. 6 接口契约

| 接口 | 入参 | 返回值 | 关键实现要点 |
|------|------|--------|--------------|
| `init(_ext)` | 扩展字段（可空） | `{}` 或 `{ ext: {} }` | 把 `ext` 存到本模块的全局变量，让后续接口读取 |
| `homeContent(filter)` | `{ filter: {...} }` | `{ class: [...], list: [...] }` | 返回首页分类与推荐列表 |
| `categoryContent(tid, pg, filter, extend)` | 4 个参数 | `{ list: [...], page, total }` | 同步 fork 兼容：第一个参数是对象时按对象解析 |
| `detailContent(ids)` | `ids: string[]` | `{ list: [VodDetail] }` | VodDetail 含 `vod_play_from` / `vod_play_url` |
| `playerContent(flag, id, vipFlags)` | 3 个参数 | `{ url, parse, header?, flag? }` | `parse: 0` 表示直链；`parse: 1` 走 parses |
| `searchContent(key, quick, pg)` | 3 个参数 | `{ list: [...] }` | `quick=true` 时允许即时搜索 |

**字段命名**：遵循原版 TVBox Wiki，多仓扩展字段写为注释（见 `docs/扩展字段.md`）。

**VodDetail 必填字段**：`vod_id`、`vod_name`、`vod_pic`、`vod_play_from`、`vod_play_url`。

**`vod_play_url` 格式**：`来源1$类型1$URL1#集数2$类型2$URL2#...`，多个来源用 `$$$` 分隔。

## 3. 30 分钟接入流程

### Step 1：复制模板

```bash
cp src/spiders/_template.js src/spiders/<your-site>.js
```

### Step 2：修改基础配置（5 min）

打开 `<your-site>.js` 顶部：

```js
var SITE_KEY = '<your-site-key>';            // 唯一 key
var SITE_NAME = '<显示名>';
var API_BASE  = 'https://<your-real-host>';  // 已通过合规审核
```

### Step 3：实现 homeContent / categoryContent（10 min）

- `homeContent`：从 API 拉首页列表，map 成 TVBox VodItem 形态。
- `categoryContent`：使用 `tid`（分类 id）/ `pg`（页码）构造请求。

### Step 4：实现 detailContent / playerContent（8 min）

- `detailContent`：把 `ids[]` 传给 `detail?ids=...` 接口，回填 `vod_play_url`。
- `playerContent`：把 `id`（`vodId$ep` 形式）拆解为单集 URL；返回 `{ url, parse, header, flag }`。

### Step 5：实现 searchContent（5 min）

- 调搜索接口，把结果项映射成 VodItem。

### Step 6：本地自测（2 min）

```bash
# 单元测试
node --test tests/spider-mock.test.js

# 直接跑 6 接口（输出 JSON）
node tools/scripts/run-spider.js src/spiders/<your-site>.js

# 源 JSON 校验（如改源 JSON）
node tools/scripts/validate-source.js dist/source.json tools/schemas/source.schema.json
```

### Step 7：构建 self-contained 产物 + 加入源 JSON

```bash
# 1. 打包到 dist/spiders/<your-site>.js
node tools/scripts/build-spider.js

# 2. 在 dist/source.json 中追加 site entry：
#    {
#      "key": "<your-site-key>",
#      "name": "<显示名>",
#      "type": 1,
#      "api": "https://<owner>.github.io/<repo>/spiders/<your-site>.js",
#      "headers": { ... },
#      "custom": { ... }
#    }

# 3. 重新校验
node tools/scripts/validate-source.js dist/source.json tools/schemas/source.schema.json
```

## 4. 容错模板（推荐）

所有 6 接口统一使用 `tvboxBase.withFallback(fn, fallback, logger, apiName)` 包住：

```js
function homeContent(filter) {
  return tvboxBase.withFallback(async function(){
    var data = await base.fetchJson(API_BASE + '/home');
    return { class: [...], list: data.items.map(toVodItem) };
  }, function(){
    return { class: [], list: [] };   // 异常时返回兜底，TVBox 不会崩
  }, logger, 'homeContent');
}
```

异常会落 ERROR 日志并返回 fallback；不抛未捕获异常。

## 5. 配置项由源 JSON 控制

源码：

```js
var base = tvboxBase.createBase(SITE_KEY, {
  headers: { 'User-Agent': 'Default-UA' },
  custom: { timeoutMs: 5000, enabled: true }
});
```

源 JSON 覆盖：

```json
{
  "key": "<your-site-key>",
  "headers": { "User-Agent": "Override-UA" },
  "custom": { "timeoutMs": 1500 },
  ...
}
```

`headers` 与 `custom` 会按层合并（深合并），Spider 内 `base.config.headers` / `base.config.custom` 自动反映最新值。

代理：

```json
{ "proxy": "http://127.0.0.1:7890" }
```

## 6. 日志规范

每次接口调用产生 1 行：

```
[tvbox][<site_key>][<api>] status=<status> elapsed=<ms>ms url=<url> error=<error>
```

- `status`：HTTP 状态码；网络错误时为 `network`。
- `error`：失败原因；成功时为 `null`。

敏感 header（`Cookie` / `Authorization` / `X-API-Key` / `X-Auth-Token` / `Proxy-Authorization`）会被自动 mask。

日志落盘样例见 `examples/log/example.log`。

## 7. 本地调试技巧（无需 TVBox 客户端）

```bash
# 1. 串行 6 接口（dump 全部结果）
node tools/scripts/run-spider.js src/spiders/example-mock.js > /tmp/run.json

# 2. 单接口试调
node tools/scripts/run-spider.js src/spiders/example-mock.js --api=categoryContent --print

# 3. 替换 args
node tools/scripts/run-spider.js src/spiders/example-mock.js --api=detailContent --args='[["m001","m002"]]' --print

# 4. 验证源 JSON
node tools/scripts/validate-source.js dist/source.json tools/schemas/source.schema.json
```

## 8. 常见问题

| 问题 | 解决 |
|------|------|
| TVBox 客户端加载后 home 为空 | 检查 `dist/source.json` 是否可被公网访问，浏览器打开 `source.json` 看是否 raw JSON |
| Spider 报 `module is not defined` | 检查 Spider 是否为 self-contained（运行 `node tools/scripts/build-spider.js`） |
| 修改源 JSON 后行为未变 | TVBox 端缓存过旧；用户需在 TVBox 中"重新订阅" |
| Spider 频繁超时 | 调大源 JSON 中 `custom.timeoutMs` 或减小单页元素量 |
| 日志出现 `***` 字样 | 敏感字段被 mask（符合 L-3）；如需明文请使用非敏感 header |
| Logger 输出到文件 | 在 `tvboxBase.createBase` 传入 `logSink(level, line)` 自定义落地 |
